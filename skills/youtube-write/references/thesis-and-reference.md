# 主旨与参考风格

适用于明确表达立场的观点视频，尤其是一口新饭参考或“概念太多、主题不突出”的返工。不是所有视频的固定模板；教学、新闻与开放讨论按其目的组织。

## 先确认回答了什么

用一句自然口语写下“我认为……，因为……”。将它写入 editorial.thesis；适用条件保留，但不能只剩条件。开头在提出具体矛盾后明确立场，结尾回到已论证的理由和行动，不再新增一套知识点。立场可以是用户已表达的判断，也可以是依据已核验材料形成并明确标识的本次独立研究建议；不能为了强烈而编造。投资类稿先按 [独立研究与投资主张](investment-thesis.md) 写出经营与估值落点，再展开例子；不以资料逐条播报代替论证。

每段的 argument.point 回答：它给主张增加了什么理由，解决了哪一个阻碍观众接受主张的疑问？如果删掉整段不影响理解或接受主张，优先删去、并入一句或移到研究笔记。数据承担处境或证据任务，不默认铺一段市场播报。

例：“应该在熊市买入”的主线可以是“同样的未来收入，以更低买价取得 → 等到安心可能要多付钱 → 不必买在最低点也能按计划开始”。市盈率、回购、现金流、AI投入即使都正确，也不应各开一节，除非其中某项真正改变本期结论。

## 一个例子逐步变化

优先选择能贯穿主要推理的具体对象。先给出起始关系，随后只改变一个条件，再回应观众自然产生的疑问。回到同一例子必须增加新的理解，不能只是重复金句。对象与数字不因换段重置。

例：同一公司每年假设分配10元，买价200变100，用来说明购买条件；随后收入10变5，用来说明失效条件。两者都是假设，不能据此证明某只现实股票已低估。真实公司研究应保留日期和未知项。

当新品发布触发一次投资复查时，把作者原有判断放回一个具体工作场景。沿同一任务追到续约或回款，只在产品改变了某一步时引入它，并核实首发平台与测试范围。结尾说清原判断中哪一部分仍成立、哪一部分要等新的经营证据。

## 边界的组织

将必要前提贴着相应推理讲清，对主要反例集中解释。避免每说一个买入理由，立刻插入一遍完整的风险清单，导致全片只剩“可以考虑研究”。也不能为突出主旨删除会推翻结论的反证、资金约束，或许诺必然回本。

## 借鉴一口新饭的什么

依据本项目[特斯拉参考片分析](../../../docs/research/yikouxinfan-tesla-video-style-analysis.md)：具体个人疑问、明确判断、递进反问、例子与真实经验承接、稳定页面上的重点移动、声音辅助部分段落转折。浅色页面只是表层，不应靠重复换标题卡宣称风格相似。

有真人素材时，让真人承接态度和经历；没有时，在 brief 明确采用旁白版本，以真实素材、摄影拼贴和连续对象解释承接，不冒充已复刻真人在场感。参考片的台词、人物、声线和素材不直接复用。分析未完成完整主观听审，不能将某种乐器、BPM或曲风写成已验证的参考特征。

压缩样片时保留至少一条对本题有作用的作者来由或真实处境；不是硬凑个人故事。检查“我认为”背后能否指出已核对的经历、判断变化或付出的代价。不要把这些全删掉，仅留下通用反问和算术例子，再指望音色补回作者身份。缺少可用经历时保持诚实，以具体研究过程承接。失败案例及执行核对见 [参考风格对照](../../youtube-produce/references/reference-style-review.md)。

## 写完审读

1. 不看标题，只读开头和结尾，能否说出同一个明确主张？
2. 每一章能否解释它为何让这个主张更可信，而非只是又介绍一个概念？
3. 去掉画面后，例子、反问和条件能否独立听懂？
4. 结尾是否给出与标题相符的选择，而没有退回泛泛的“理性、谨慎、做好研究”？

这是 Agent 的内容审读，不是现有 validate/review 自动实现的语义判断。
