# 实拍与连续对象动画

以观点为主线，先决定画面中的对象发生什么变化，再选择实拍、照片、图解或文字。相邻句子讨论同一关系时，优先让同一对象留在场上继续变化。摄影拼贴保留为局部版式，插画用于确有解释作用的比喻；不把任一素材类型做成全片配额。

读 [视觉规则](references/visuals.md) 完成对象、动作与文字分工。实际编辑或渲染视频时再加载环境中的 hyperframes 入口及所需能力；仅修改文档不启动制作。口播采用作者录音或已选定的正式 TTS，视觉改版不自动换声音。

用户反馈布局散乱或主次不明时，执行 [语义分组与整幅构图](references/visuals.md#语义分组与整幅构图)：先让完整判断或关系式形成一个视觉组，安排旧对象退场，再核对字形对齐与边框尺寸。不能把单个框内居中通过当作整幅构图合格。

用户反馈画面杂乱、素材无关或看不清主线时，先执行 [素材相关性与减法审阅](references/visuals.md#素材相关性与减法审阅)。画面里的每个主要元素都应帮助识别对象、核对证据或理解变化；“与财经有关”“增加真实感”不足以成为保留理由。先删去争夺注意力的元素，再判断是否需要新素材。

参考一口新饭时，先承接 [主旨与参考风格](../youtube-write/references/thesis-and-reference.md) 的问题链。稳定构图中切换当前解释的对象、数字或强调位置；保持口播比屏幕文字更丰富。画面变化由新疑问、新证据或条件变化触发，不规定几秒换一次，也不把“浅底大字”当成全部风格。没有本期真人录像时明确采用旁白方案，不能保留虚构 footage 路径后声称可交付。

人物在参考片中承担的态度、手势和关注点切换，不能随真人窗口一起删掉后不再处理。按 [参考风格对照](../youtube-produce/references/reference-style-review.md) 为旁白方案重新安排真实材料与可见动作；重要切口记录前后关注对象、声音是否延续及采用该剪法的理由。默认淡入不是已完成的剪辑设计，尚不支持的转场或镜头动作列为实现缺项。

## 封面照片与频道标识

封面主标题直接表达本期问题或观点，不默认加“我的复盘”“我的港股复盘”等身份或材料说明作为主/副标题。副标题没有增加必要信息时省略，连同其装饰线和空容器一起移除；不能为了填满模板而补字。复盘材料仍可作为视觉主体，纸面真实原文与面向观众的封面标题分别处理。用户另行明确要求栏目名称时按本期要求执行。

用户已认可“真实复盘节选＋手持笔圈注”的封面方式。对于以作者复盘、研究过程或投资判断为主的主题，优先采用真实材料承载观点、一个有意义的动作突出关键句、简短标题和右下角原版logo的摄影式构图。沿用温暖、平静、有人在思考的感觉；每期重新选材料、圈注内容和构图，不固定复用某个日期、原句、纸张或手势。不以此偏好替代不适合复盘材料的主题所需的直接图像。

封面照片根据本期最终脚本生成：先提炼核心观点、观众面临的具体处境，以及一个能承载该观点的主体/动作，再确定摄影式构图。不能仅按标题关键词生成通用股市、办公楼或咖啡馆图片。提示词注明主体、环境、动作、情绪、裁切比例，以及标题和右下角logo的留白；脚本主旨改变后重新判断照片是否仍适合。由 [youtube-media](../youtube-media/SKILL.md) 保存实际生成文件与来源记录，照片表达情境，不冒充真实新闻或作者亲历的现场照片。

封面选图先做“第一眼会被认成什么主题”的检查：主体、道具和动作是否容易把股票主题误读成房地产、购物或其他内容？写出最可能的误读，优先更换主体或补足直接关系，不能只靠标题解释一个含义含混的比喻。静物隐喻需要可见的差异或动作；两枚没有信息的价签并不能表达价格变化。缩至约320像素宽检查主体、主张和情绪是否仍成立，精细材质与大图好看不能替代主题辨识。

作者观点型封面可比较人物态度、真实复盘材料、直接解释关系等不同方向，选择能够呈现本期判断的构图；不把“财经杂志式”固定为豪华建筑模型和空旷桌面。人物方案使用作者确认的人像，研究材料保留真实来源，模拟数字沿用脚本的假设边界；不虚构已买入、盈利结果或实际新闻。被否定时比较主体与叙事不同的方案，而非只换配色和角度。用户仅要建议时交付具体画面、标题和取舍，不自动生成图片或重渲染视频；已授权制作时按既有授权推进。

封面右下角必须独立叠加作者原版“面朝北北”logo。公共原件为 [mianchao-beibei.svg](../../resources/branding/mianchao-beibei.svg)，来源与哈希见 [素材记录](../../resources/branding/mianchao-beibei.provenance.json)。按原比例放置并保留安全边距，保证缩略图可辨识、不遮挡主体和文字。生成照片时只预留位置，不能让图片模型重画logo，也不能用键入“面朝北北”的文字临时代替。先核对实际导出封面中的位置、比例、对比度和裁切，再标记完成；规则更新不代表历史封面已更新。

封面验收同时检查多余文字：生成工具、提示词和“摄影式概念场景”等制作说明保留在来源记录中；不为明确的概念画面默认增加一行制作标签。现有镜头 `note` 默认会显示，需在分镜中明确设置 `show_note: false` 并核对导出帧。理解判断所必需的假设条件与真实素材署名分别保留。

## 从解释任务到可渲染分镜

以 [trade 研究交接](../youtube-write/references/trade-context.md) 中的主张与证据为依据：旁白表达判断，证据支持事实，动画解释关系。每章先选需要持续辨认的对象及其变化，不把 trade 的每个标题或表格都变成一页画面。假设对象和真实公司资料明确区分；待验证回报、估值情景和作者偏好不能画成已发生结果。

1. 先写清对象、变化前状态、动作、变化后状态、口播锚点和必要条件。同一场景可跨多个 unit；unit 是语义/音频分段，不等于换页。
2. 真实活动或环境可用实拍建立情境；分流、复制、分配等关系用连续对象解释；事实判断用可核对的原始材料；关键问题或结论用短句停留。
3. 缺素材交给 [youtube-media](../youtube-media/SKILL.md)，按主体和动作搜索。进入编排前确认实际文件、可用区间、裁切、许可和用途。
4. 按 [作者契约](../youtube-write/references/authoring.md) 回填当前支持的字段。规划内容可记录在 brief.json，执行以 script.json 为准；不把尚未实现的规划字段说成渲染能力。
5. 按真实词时间安排动作。检查原对象与目标对象的关系、复制路径、变化前后状态、阅读停留和必要字幕；避免每个字都采用同一种入场效果。

## 当前能力选择

| 表达任务 | 当前入口与边界 |
|---|---|
| 真实服务、交易等动作 | footage：本地视频，按实测镜头时长裁切，剥离源音轨；不是新闻事件证明 |
| 进入、顾客分流、优势复制 | continuity / shop-competition/v1：跨单元保留同一场景，只支持完整的假设街区机制 |
| 照片承接、必要并置 | collage / hero、duo：局部使用，不默认每段一张标题页面 |
| 概念与机制 | comparison、flow、mechanism；关系须明确，旧条形示意只在量的含义确实清楚时使用 |
| 数量分配 | quantity：仅固定持有量/变化总量，不用于任意经营数据 |
| 关键判断、必要比喻 | claim、illustration；不复述整段口播，不默认全片插画 |

新增 object_scene 与 evidence 的范围见下文；其他连续动作与真实数据图表仍需扩展。不能把咖啡店模板套到所有主题，也不能将“支持连续动画”描述成通用自动分镜器。

验收实际 MP4 的关键动作前、中、后帧与字幕安全区，尤其检查运动中文字碰撞和裁切。机器检查、抽帧审阅、连续播放、听审分别记录；参考完整流程见 [youtube-produce](../youtube-produce/SKILL.md)。

标题上移、日期或正文随后进入时，检查整个移动路径，不只检查起点和落点。新元素位于旧元素经过的位置时，应按后续口播词锚点延后进入，先让位再显现；验收需包含该次移动的中间帧，避免短暂叠字漏过静态排版检查。

完整篇启用章节导航时，使用短而可读的章节名，按实际旁白边界计算导航与跳转时间。逐项核对片内导航、导出播放器标题和本期 script.json，防止沿用其他剧集名称；检查导航显示后正文仍有安全间距。数值图解中的标签必须随语义区分已支付的买入价、当前报价与假设收入，不能把价格变动动画画成历史成本变化；基准条和当前值条应在实际导出画面中可区分，不能仅凭输入颜色字段判断生效。

同一数值图解再次出现时，先明确本次新解释任务，按它改变关注对象与构图，不复制整页“股权＋买价＋收入＋百分比”作常驻背景。确需承接的数字和长度保持上次落定值；再检查动作中和动作后。问题切换在新对象进入时让旧问题彻底退场，除非口播此刻确实在比较两者；不要用长期低透明度残影代替退场，也不要在等待新词锚点时留长时间空画面。

章节导航各段按实测时长铺满安全区，标题在各自区段内居中，完整保留 01、02、03 等序号。标题较长时优先缩短文字或一致调整字号；极短章节可两行排版，不能单独删除序号，也不能改变时长比例来伪造平铺。实际全宽截图检查首尾边距、全部序号、区段边界与当前进度。

原文复盘材料按讲述先交代情境，再逐句进入关键原文，最后突出判断；不能整页原文在镜头边界瞬间全亮。只保留观众理解所需的日期或出处，“作者经历”“原文节选排版”“画面为原文排版”等制作说明留在来源记录中。截图上的用户红框按问题标注理解，不复制进成片。检查入场前、中、后和下一句的接续，而不只检查静态排版。

文字密集图解之间使用溶解时，先让旧正文退出，再引入新正文，背景可以延续；不能让两组大字在过渡中叠读。被调淡的对象退场时从当前透明度继续降低，不能先恢复全亮再消失。复盘日期出现时保留必要情境，避免只剩日期悬在大片空白上。

## 新的解释模板

按 [解释场景契约](references/explain-scenes.md) 使用 evidence 与 object_scene。前者显示真实原文截图并局部高亮；后者支持同一对象改变情境、对象关系逐步展开，可跨语义单元保留身份。需要照片对象时先获取实际素材。

新项目默认 opinion-explainer/v1，无固定刊头和页码；旧配置兼容。默认风格不等于全片强制一种版式。先让画面承接完整意思，再根据疑问、证据或尺度变化换景；统一配色、标注和字幕，而非统一每个镜头的布局。

## 简洁数字、开场叠层与片尾

财经画面中的数字默认不使用千位逗号，保留原数值、有效小数位、单位与来源；例如展示 23294.42，不改为另一个精度或把来源原文篡改。封面标题非必要逗号可用断行代替，真实引文保持原文。

免责声明是视频叠层，不是封面照片内容：短框随文本自适应、允许两行、慢淡入 → 完全可见 1 秒 → 淡出，在第一处切镜至少 0.2 秒前消失。分别检查透明、半透明、全显、退场和下一镜头帧，并独立导出不含免责声明或旁白字幕的封面。

末段不要只有一句大标题一直站到结束。让研究、条件和行动按实际声音顺序出现，结尾保留有设计的落款与音乐尾声。落款避免重复两个 logo，导航先退出，频道标识和短句缓慢进入；验收须看最后口播到音乐结束的完整连续段。

## 视觉改版的方向确认

观众反馈“像 PPT”时，按作者选定的媒介修镜头。保留笔记和账本的项目，先找一件可以持续追踪的东西，让它随论证改变：笔迹从旧假设移到证据，收入和成本共用刻度，可撤投入从成本带中退出。原状态退到旁边供对照。字幕关掉后，观众应仍能指出哪件东西发生了什么变化。整体推进由因果或视点承担。录制前先列出这些变化；导出后检查运动的起点、中间帧、落点和下一条件的接续。切到实拍、真人或跨媒介混剪属于另一个方向，只在用户选择时采用。

作者要求先看参考并确认方向时，从参考作品选一处真实切点、一处解释对象如何变化，与自己的实际片段或明确标记的分镜草案对照。用本期材料准备少量代表画面，把“这个镜头随哪句话改变、改变后观众看什么”写清楚。区分可用素材的推荐版与需要额外拍摄的备选版。确认范围写明是美术方向、局部试片还是整片制作；静态讨论稿不能作为已批准风格、动态验收或已经修改正式分镜的记录。
