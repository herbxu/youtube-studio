# 原文高亮与连续对象契约

以下能力已经接入 validate、align、assets、compose。仍使用 opinion-script/v1，旧模板兼容。脚本只写实际口播 cue；事件秒数来自对齐，不把创意预估当语音时间。

## evidence：真实资料局部高亮

必要字段：id、kind=evidence、cue、purpose、headline（1–26 字）、note、asset、provenance、credit（≤90 字）、source_id（有效来源）、page（原文页码/位置）、source_sha256（截图哈希）、events。

事件：`{"action":"highlight","cue":"研发投入","rect":[0.1,0.2,0.8,0.12],"label":"这是用途计划，尚未证明回报","duration":0.55}`。

rect 是截图的归一化 x/y/宽/高，必须在图内。多个高亮按口播顺序切换，原始截图不重写。可以截取原 PDF 的一个区域，但 provenance 必须记录原文件哈希、页码和裁切坐标；不能重排或生成原文。截图变化会触发哈希校验失败。PDF/公告的获取与内容核验仍由 agent 完成，不是自动搜索能力。

画面保留原文、解释和来源三个层级。不要展示一整页小字后宣称观众已看懂；选择能支撑本句的局部，并保留足以防止断章取义的上下文。

## object_scene：同一对象改变情境、关系逐步展开

必要字段：id、kind=object_scene、cue、purpose、headline（≤26 字）、note、scene_id、variant=context/relation、objects、events。

objects 为 1–6 个对象：`{"id":"company","label":"同一家公司","shape":"card","x":800,"y":400}`。shape 为 card/token/company/cash/person/document；后四种为代码绘制的解释对象，不是新闻图片。x 范围 140–1480，y 范围 310–540；对象宽 300，高 180。可加 asset 与 provenance，使用本地位图作为实物剪贴；有图片时高 240；代码对象高 270。标签≤14字，实际画面还需检查长度与碰撞。

动作集合有明确边界：

- reveal：target 首次出现，每对象只允许一次。
- move：target 移动到绝对 x/y，保留身份。
- emphasize：target 边框转强调色。
- context：label（≤36字）切换情境说明，原对象留在场上。
- connect：target 向 to 绘制连接，两者必须已经出现。已连接对象暂不允许继续移动，避免连线与对象脱离。

每个事件包含 cue，可选 duration（0.1–1.5 秒，默认 .55）。同一 scene_id 的镜头必须连续、objects 和 variant 完全一致；跨 unit 不重新创建 DOM。标题由场景第一镜头定义，条件 note 可随单元替换。第一镜头声明完整对象集合，之后用事件逐步揭示，不要求所有对象同时出现。

这不是任意图表或物理仿真。真实数值用 quantity 的受限公式，其他数据图表需另行实现。连线说明关系而非自动证明因果；note 必须交代假设。复杂分配、曲线、任意连接后移动、摄像机跟随尚未实现。

## 验收

检查每个动作前、中、后和倒序定位；保持对象身份、方向与位置，核对文字碰撞和字幕安全区。证据高亮必须对应原图真实区域；标签不能比原文作出更强判断。对象重复慢推拉、每句换背景、所有字滑入不算解释能力提高。

## essay_scene：摄影与个人记录

用于把已核对的个人记录与摄影情境相接，以及解释同一份收入对应不同买价。入口为 `kind=essay_scene`，保留实际图片 asset、provenance、credit、headline、note。重新排版的引文不冒充原始文档截图；排版方式记入来源元数据，不默认在观众画面加“原文节选排版”等制作说明。

`layout=clean` 用于已确认摄影不增加理解的镜头：不填写 asset/provenance，不渲染照片与金币，也不允许 photo/coins 动作；保留必要来源 credit（纯假设/判断可为空）、记录出处与假设条件。记录放大必要节选，数值场景保持价格与每年收入的位置。默认 `layout=photo` 兼容已有作品，不批量更改历史镜头。

clean 数值场景可用 `previous_income` 配合 `reveal income`：口播锚点之前显示原收入，到锚点才变为新收入；价格使用 `previous_price` 同理。不能提前显示尚未讲到的经营恶化结果。改后验证实际画面和倒序定位，删除素材字段不等于渲染器已经去掉装饰。

clean 记录可填 `quote_lines` 按意思断行，各行拼接必须与 quote 完全一致，不能借排版改写原文。纯数值布局的倒序定位检查：`node tests/check_essay.cjs <剧集目录>`，覆盖原价格、原收入保留至口播锚点及无装饰素材。

当前 clean 记录的正文仍是整页显示，不具有逐句入场能力。用户要求随讲述展开时采用下面的 motion 布局：把原文行分别建为对象，绑定不同口播 cue，并安排强调线及退场；quote、quote_lines、record_date、source_id 留在源文件核对。不能只给整页加溶解就声称实现了逐句展开。

clean 数值场景的 `previous_comparison` 可保留上一场的已读算式/说明，直到本场 `reveal rate` 的实际锚点才退场。它必须与仍在展示的数值一致；价格改变时应同时移除旧算式，不能为延长停留制造错误对应。安排理解时间应先减信息量，不把算式留到镜头最后才闪现。

- `variant=record/closing`：quote为原文节选（不超过80字），record_date保留历史时间，source_id对应已核对来源；subline为编辑解释，不冒充原话。
- `variant=question`：短问题或判断，摄影配图不充当事实证据；subline只承接必要解释，不用整段文字占满画面。
- `variant=business/valuation/risk`：hypothetical=true，price与income为正数，previous_price可选，comparison显示算例说明。金额与百分比须按本期假设核对。当前金币示意仅支持收入10元及降为5元的示例，不推广为任意数量图。
- events支持mark／focus／reveal；target为photo／marker／price／income／rate／coins，cue来自真实口播，duration为0.1–1.5秒。各variant只选择实际存在的目标；reveal price且提供previous_price时，原价保留到口播锚点后再退场。

直接切换使用transition=cut，不额外插入静音。记录、假设与态度分别承担任务，不把这些版式重新变成每句一页。抽查实际画面中的单位、金币、算式、字幕和原文高亮；参数传递、编排与真实观感分别验收。

### motion：按口播建立对象、改变状态

ticket/stamp 的文字与边框共用一个动画父对象。内部文字层按本地 Noto Sans SC 的实际字形边界和550字重做光学校正，不再只居中字体行框；stamp不使用导致末尾留白的字距。`node tests/check_motion_alignment.cjs <剧集目录>` 检查真实浏览器的字形中心，在进入、旋转和落定状态与框保持一致；随后查看MP4裁图。换字体或字体版本要重新校验，不把当前偏移量硬编码到其他模板。

`layout=motion` 是已接入的独立编排方式，保留 `kind=essay_scene`、`variant`、目的与备注。个人记录仍要求有效 `source_id`；business/valuation/risk 仍要求 `hypothetical=true`，必要假设通过可见对象保留。此布局不自动把 headline、note、来源台账或整段引文铺在屏幕上，不接收装饰背景 asset。

`motion_objects` 为 1–14 个有明确作用的对象，各有唯一 `id`、`type=text/ticket/stamp/value/bar`、`x/y/w/h`；安全区 x≥80、y≥50、右边≤1840、下边≤890，字幕区域另留。`text`≤32字、`label`≤14字、`font`24–190、`color`为hex；value 填 `value` 数字，bar 的 `portion` 为0–1。默认不可见，`initial=true` 只用于确实应继承的已讲对象，不用于整页预展示。

events 仍以真实口播 cue 对齐，duration为0.1–1.5秒。`reveal`从隐藏位置落位，x/y为进入的相对位移；`move`的x/y为相对原始位置的绝对偏移量；`strike`用于概念印章落位，不冒充真实文件印章；`dim/restore`弱化/恢复次要对象；`hide`退场；`focus`增大并转强调色。`count`仅用于value，填from/to；`bar`仅用于bar，填from/to比例。起值必须与先前状态一致。所有动作运行于单条可定位的时间线，目标不能是不存在的对象。

这是有限的对象与数值动画，不是任意图表或自动设计。成本条的比例与价格、数值与收益关系仍须编导核对；跨镜头对象用相同位置和状态承接，但当前不会自动合并成跨镜头DOM。完整数值变化与进入前隐藏状态执行 `node tests/check_motion_essay.cjs <剧集目录>`，再用HyperFrames截图及实际MP4核对。直接打开HTML而未接入框架的clip显隐不能作为最终画面证据。

### 投资笔记与账本试剪

实拍镜头使用 `kind=footage, layout=film` 时，可以用 `labels` 与 `label_cues` 随口播依次落下少量数字或原文。每条标注在下一条或本镜头结束时离场。两路动态画面需要各自题注时，可在一条文字内用制表符分开左右两栏。署名和假设条件随素材保留，字幕使用适合实拍的明暗对比。按实际镜头内动作选择剪入点，另查导出后视频与原片帧序是否一致。

笔记逐句出现可在 motion 布局使用 `surface=notepaper`，首帧给出记录日期和当时的判断。按实际口播逐行引入自问，划线对准语音正指向的词。账目变化可用 `surface=accountbook`，数值文本设 `align=right` 并保持行列位置。收入或成本改变时让旧利润退场，听到新结果时再进入。用实际 MP4 比较固定变量所在区域，检查变化前、中、后的数字与声音是否相符。

引用原图需要在旁边显示观测期和数值时，evidence 可设 `layout=beside`。高亮框仍按原图归一化坐标定位。导出后检查图例、数据点、期间及字幕的字号和相互距离。

用账本比较互斥假设时，让共同的收入留在两列上方。第一种情形落定后保留合同义务、成本和结果，第二列随第二种情形的旁白进入。把“已签约仍须付款”“尚未签约可以取消”等条件放在对应数字旁。缩成手机大小检查观众能否同时辨认共同前提、两种条件和两个结果。参考图截取局部时记录裁切来源，重新换算高亮框坐标，并保留统计期间与指标定义。

### 连续纸面动画

在 essay_scene 中使用 layout=paper-animation。drawing 保存组合图形、文字、纸条和有来源的剪贴图片，events 用唯一口播锚点驱动有起止值的笔迹、位移、比例、旋转与透明度。record 段写明原文和剪贴出处，原图核对哈希。账本金额及差额共用同一图尺，利润由收入减成本计算。改变假设时保留实际已读的旧状态，并把参考值标为“上期”或对应情景。验收时应在成片中测量收入/成本的端点、差额方向及跨段的固定位置；仅检查文字数值会漏掉长度不成比例的错误。

观众反馈纸面底色抢眼时，选同一帧、同一尺寸对照。先单独调整外沿明度、纸面冷暖和阴影，再检查纸上颜色各自表达什么。账本里如果常规收入和盈利结果都用绿色，可把基础数据改为灰蓝等中性色，让盈亏各保留稳定的颜色和文字标识。用真实导出的笔记与账本各取一帧缩到手机尺寸，检查原件剪贴、细笔迹与小字是否还看得清；再沿一次收入或成本变化看完整段动画。保留旧版以便同帧比较。

将已确认的纸面试剪扩展到整期时，财报、行业图表和作者判断可使用 paper-animation 的 analysis 变体。给每页指定真实 source_id，使用剪贴时登记来源、裁切和成图指纹。来源数值标明期间与分母；假设账本继续使用 business 并在画面写明假设。口播拆成两段时，让第二段从上一段的物件位置与已出现的批注接续。至少选一处跨段和一处数值变化，在最终成片逐帧复核。

连续试剪先从真实成片中的一个观看问题推进到下一个，检查每镜第一帧已经出现哪些文字。数字、批注和结果跟随口播进入，前一项适时滑出；入镜时只给观众一个视觉焦点。缩略图另查真实笔记引文和右下原版 Logo。在普通播放器里检查片内导航和角标；仅在试剪之后才讲的章节可以作为低对比度的预告标签，不给它们虚构时长或跳转点。

频道角标与产品 Logo 分工：角标在独立封面、片内封面和正文共用同一宽度、右下边距和原始比例，产品标识靠近对应名称或随预算、界面进入。在实际成片缩至手机宽度后，分别比对改前改后的角标宽度和字幕净空。给纸面增加多张素材时，为每张剪贴保存独立来源和指纹，在涉及产品时展现界面，进入算例即让图表成为焦点。读财报时优先取能完整辨读的一句，随口播进入并退场。

导出后把封面和正文按同一分辨率对照，核对角标的实际像素边界及最长字幕净空；在封面转入正文的连续帧中检查角标是否跳变。

重读历史决策时，封面纸上的复盘日期与当年决策日期分别核实。缩至手机宽度检查明暗、日期与标题辨识度；如果展示图本身由多张小海报组成，优先换成单一主体并扩大图片的画面占比，配合独立数字区。

产品图放大有效界面，去掉多余厚框，在算例开始时让界面退场。行业图先交代期间、指标与比较基准，再依口播放大对应原始基准线；区分行业均值和单产品。画面去掉“作者投资笔记”等制作标签。用同一商品说明支付行为的不同起点，消息列表只用于通讯。片头圈注与问候同时启动，片尾在实际告别后检查有画面的落款停留。

固定片尾用与频道有关的单一摄影主体承接收束，例如研究笔记本。把频道名、定位和道别放在同侧留白，动作按旁白先后发生。检查最终告别前后连续帧及手机宽度末帧，确保静物、字幕和原版角标各有空间。

在手机宽度的实片上把关键帧和同一 MP4 的录音一起核对，重点看超短字幕、章间停顿和告别。可用 captions.minimum_display_seconds 延长短字幕的退场，保留首字入场时间，且不侵占下一句或下一镜头；已确认的落款静帧另行检查。

作者要求沿用原版时，固定同一镜头、素材和字幕，按手机宽度并排比较原色与候选底色，检查暗部、边缘和小字，再连看一遍新增的入场与退场动作。试剪反馈落到时间点，记录问题、改法与导出后的复核结果。
