# 合并同一期与导出上传素材

适用于同一选题分散在早期稿件目录和完整制作目录的情况。先看实际脚本、运行状态、素材和成片；不能只按目录日期决定哪个更完整。

## 合并

- 优先保留已验证且引用稳定的生产目录作为唯一正式根目录。早期目录完整迁入 `youtube-workbench/episodes/<ID>/source/development/<原目录名>/`，保留原稿、来源、配置和早期构建资料；不拿旧 script/config 覆盖现用输入。迁入前后逐文件核对 SHA256，不因重复或 Git 忽略而删除。
- 检查运行锁与任务状态，运行中不迁移。记录旧路径、新路径、原件指纹、引用修改和原 QA；历史记录中的旧路径可以作为审计数据保留。
- 更新 brief、策划文件、样片来源和文档链接中的活动路径。来源仍指向实际采用的历史稿件，不能因合并而误写成后来版本。
- 对正式目录执行 validate、doctor 和必要的流水线验证。仅来源路径改变且媒体、脚本和配置未变时优先复用缓存。更改 brief 也会改变输入指纹；实际验证后才更新当前 QA/review 的绑定，并保留原绑定和迁移证据。不把路径替换冒充重新渲染，也不把待听审变成通过。

## 上传包

- 在 `deliverables/youtube-upload/` 导出唯一明确的当前成片、无声明封面、UTF-8 基础 SRT、标题、简介与章节、标签和简短使用说明；置顶评论可按内容提供。另导出 ZIP，ZIP 本身放在包目录外。
- 公开素材按白名单打包：不要混入 trade 原始笔记、本地路径、账户信息、配音参考、凭证、旧 MP4、生成缓存或内部 QA。检查 manifest 内也没有绝对路径；记录相对文件名、大小、SHA256 与所用成片版本。
- 视频直接复制已确认版本并核对哈希，不为打包额外压缩。封面保留已认可的设计与真实 logo，必要时仅作格式导出，不能把视频叠层或旁白字幕烧进封面。大尺寸建议不代表需要把小源图机械放大。
- 标题、简介与标签以实际成片为准，保留行情截止日期、假设与适用条件。只公开本片实际引用的必要来源；不要把私有 trade 文件路径写进简介。
- 从实际时间线生成章节，检查顺序、时长和正文对应。短于平台下限的片尾落款不另列为章节。SRT 必须来自同一视频版本，检查时间有效、递增、无越界；已有硬字幕时，在使用说明中指出可选 CC 字幕可能与画内字幕同时显示。
- 平台规格会变，交付时核对官方文档；将本次采用的尺寸、文件大小和链接写入说明。不要把旧的推荐分辨率或单一设备限制当成永久硬要求。
- 检查实际缩略图、媒体编码、字幕、章节、ZIP 完整性和文件指纹，再交付上传包。工程可上传与内容完整听审是不同状态，保留真实未完成项；仅导出素材的任务不自动上传、设置公开或排期。

## 自动上传与当前能力

YouTube 不要求每次手动上传。用户询问自动化时，先区分平台支持、项目是否实现、频道是否授权；不要把本地交付边界说成平台限制。每次根据实际命令入口、本机授权和接口结果判断能力，不沿用旧报告中的“尚未连接”状态。通过一次 API 操作完成上传，不代表仓库 CLI 已实现上传命令，也不代表已经配置定时自动上传。

长期自动化优先使用官方 YouTube Data API：`videos.insert` 上传视频与标题、简介、标签；`thumbnails.set` 上传封面；`captions.insert` 上传字幕。章节保留在简介内。首次需要建立 Google Cloud 项目、启用 API、配置 OAuth 客户端，并由用户在 Google 页面登录授权所需频道；不要索要账号密码或把凭证写进上传包。字幕接口所需授权范围与仅上传视频不同，按实际功能申请。

用户只问方法时说明接入步骤与尚未实现的部分，不宣称已经上传，也不擅自发出上传请求。用户明确要求接入或执行上传时，在已有授权范围内继续；未指定可见性时可建议私密预览，不能把建议说成平台强制要求。公开或定时发布按用户明确指定的状态执行。实现时保存上传会话、video ID 和分项结果，失败后核对已有结果，避免整条视频重复上传。

## 实际上传与断线恢复

- 上传前核对包内文件大小和 SHA256。先把用户指定的频道 handle（如 `@频道标识`）通过 `channels.list(forHandle=...)` 解析为目标频道 ID，再用 `channels.list(mine=true)` 核对授权频道；必须同时记录目标显示名、handle 和 ID。两次查询的 ID 不一致就停止上传并切换授权，不能因为名字相近、Google 登录成功或旧确认而放行。用户未提供 handle 且出现相似频道时，展示两个频道的实际 handle/链接再确认，不只询问某个显示名是否正确。
- 凭证文件路径通过环境变量传入；令牌与可续传会话地址保存在仓库外的私有目录，不写入 Git、公开素材包或日志。多频道的授权、上传状态和回执按频道 ID 隔离，上传去重键包含频道 ID 与成片 SHA256，不能只用片名或视频指纹。切换频道后重新核对目标，不能复用另一频道的上传会话或把旧回执当作当前成功结果。
- 收到传错频道的反馈，先核验目标 handle/ID，标记误传回执并保留证据，再处理正确频道的上传。旧视频的删除、公开或其他处理按用户明确要求执行；此前查到的私密状态不能代替当前查询，若视频已不可见则报告无法确认当前状态，不擅自声称仍存在或已删除。
- 在首次发送视频前保存 resumable session；取得 video ID 后立即保存，再分别处理封面和平台核验。网络中断后先查询同一会话的服务器 `Range`，从已接收字节的下一位继续。请求报错不等于服务器未收到数据；不能仅凭本机进度从零重传或重新创建视频。连续恢复失败、会话失效或创建结果不确定时，保留状态并核对已有视频后再决定下一步。
- 明确设置可见性，不依赖 API 的默认值。用户只说“上传”且没有既定发布安排时，可先设为私密并告知；上传成功不能表述为已公开。字幕轨是独立交付项，权限不足时保留已有画内字幕并说明未上传 CC；上传素材中的可选置顶评论不自动发布。
- 在素材包外保存上传回执，记录 video ID、观看与管理链接、频道 ID、成片指纹、可见性、元数据核验、封面及字幕结果。区分文件上传完成、平台处理完成和实际播放验收；后续封面失败不能触发重传整条视频。
- 自定义封面返回 `403 forbidden` 时，同时检查 OAuth 范围和频道功能资格；拥有上传授权不代表频道已完成手机验证。需要验证时保留已上传视频和待上传封面，由用户在 YouTube 页面完成验证后仅补封面。平台可能重排标签，核对标签内容集合，不把顺序变化误判为缺失。
- 本机存在 refresh token 不保证长期免登录。核对 OAuth 应用是否处于测试模式及其授权有效期，凭证过期时恢复授权，不重复创建 Cloud 项目或客户端。参考 [Google 应用受众与测试模式说明](https://support.google.com/cloud/answer/15549945?hl=en)。

API 文档入口：[视频上传](https://developers.google.com/youtube/data/guides/uploading_a_video)、[上传接口](https://developers.google.com/youtube/data/reference/rest/v3/videos/insert)、[封面接口](https://developers.google.com/youtube/data/reference/rest/v3/thumbnails/set)、[字幕接口](https://developers.google.com/youtube/data/reference/rest/v3/captions/insert)。配额与限制以当前接口文档为准，不把历史修订记录当作现行要求。

官方规格入口：[封面](https://support.google.com/youtube/answer/72431)、[字幕](https://support.google.com/youtube/answer/2734698)、[章节](https://support.google.com/youtube/answer/9884579)。

交付“全部产物”时，用可打开的索引标出正式版、对比试剪、试听、来源、验收和发布包。核对每个入口与包内成片指纹。频道授权、打开文件选择框和平台生成视频链接是不同进度，回执记录最后实际核验的状态。

发布与复盘分开：作品中的交付清单只链接本仓可发布文件；跨库试剪、听审与内部资料放工作台复盘清单。定稿时维护工作台 episodes/<ID>/版本索引.md 和 selection.json，写明选择范围、文件、仓库相对路径与 SHA256，未获批不推断。正式 verify 记录 deliverables/release.json，区分制作版本和事后盘点的版本；干净检出后运行 check-workspace 并检查作品库单独打开的发布清单。

交接时分别记录当前输入、历史成片指纹、机器 QA、内容审阅、全片听审、连续观看和上传回执。旧片能复算原 QA 输入指纹时登记匹配的源码仓库与提交；只有归档记录时保留证据提交及未知项。局部听审与抽帧保留范围。正式发布清单和证据随对应仓库提交，通过干净检出核验。运行缓存的私有备份需记录位置、校验方式及是否跨物理设备。

## 手动上传的独立备份

交付给作者的默认入口是独立上传目录，每部正式成片一层。用 `youtube-studio export-upload --destination <新目录>` 从 release.json 校验并导出正片、独立封面、对应 SRT 和可粘贴的标题、简介，以及本期已有的标签和置顶评论。用 `--episode` 可只备份一期。源素材、选版、渲染缓存和账单记录按工作台恢复规则保留；作者自行上传时只交付发布文件。知识学习目录以投资问题组织，直接链接现有成片或原稿。
