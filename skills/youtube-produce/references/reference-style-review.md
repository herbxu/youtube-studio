# 参考风格与失败样片的对照

用于用户明确要求借鉴参考作者，或指出转场、节奏、声音、人物感不对时。不要把每期普通制作扩展成研究项目。参考[一口新饭与熊市样片复盘](../../../docs/research/yikouxinfan-bear-sample-comparison.md)中的失败边界，数值不作为通用风格参数。

## 把值得回看的片段收进作品库

作者要求保存风格学习时，在作品库的 `风格学习/` 按参考作者维护 Markdown 笔记，从学习地图用一个具体问题链接过去。写明哪一期、约什么时间、画面或讲述做了什么，再连到本频道可用这一手法的原稿。区分样本观察、拟尝试的做法与已有试剪反馈。优先链接原片，已有研究和抽帧链接到现存记录，便于换机阅读。

## 先对照真正承担同一任务的片段

取开场、具体例子、态度转折等相关片段，对照实际成片。记录参考时间、我方时间、此刻讲什么、观众看什么、声音怎样延续。把直接看见、测量结果、创作推断和待听审分开。剧情不同不能单靠同秒数比较优劣。

“自然、像参考、节奏快一点”须落到可改的选择：删掉无作用的铺垫、重新组织句群、让价格在原对象上改变、个人反省切回说话者等。不能只加相似配色、动画或一条BGM。

## 人物与页面是一组条件

参考有真人时，观察人物是否承担态度、情绪、手势和注意力切换。保留稳定页面却去掉人物，必须补做叙述和视觉设计：真实个人材料、证据操作、对象连续动作、视点变化应各有任务。素材未到位就记录缺项，不能靠“旁白版本”几个字免除画面贡献检查；也不因此要求所有视频真人出镜。

第一人称不等于个人经历。写作应能指出作者立场的真实来源、变化或代价，不能虚构交易或给无来源的情绪加“我”。优先保留一个具体经历，而非在压缩样片时把作者身份和当下处境全删掉。

## 声音先成为连续讲述

按回忆、接续、提问、条件改变和落结论组织完整句群。停顿是区别关系的方法，普通逗号不必都停，关键问题也不能为了时长一律缩掉。音色选择、时长调整和表达演绎分开记录。

配音前按当前适配器核对表达意图是否真正进入服务请求，以及模型是否支持；不能仅因`unit.delivery`已填写就声称已指导演绎。只用统一atempo不算重新设计节奏。先在授权范围内验证一个有代表性的连续段，再批量；不能让未完成听审的结果自动变为通过，也不把它变成每一步都要用户重新批准。

声音信号可辅助查断续、接缝，但低能量区间不全是语义停顿。报告阈值、时长、区间与混音限制，不从一个样本规定固定停顿毫秒数，不自动删除呼吸或所有静音。

## 为每个重要切换写出理由

分镜记录前后关注对象、话语锚点、声音是否跨画面延续，以及选择硬切／叠化／同景变化的理由。语义unit、配音文件、画面切口不要求一一对应。参考人物与资料切换、原对象条件改变、镜头放大是不同任务，不能统一交给默认淡入。

使用实际支持的脚本字段；新镜头或转场能力未实现时列为开发项，不虚构可执行字段，不手改派生HTML。验收来自实际MP4关键切口及连续片段，既看文字可读，也看有没有长时间等待下一条信息、状态是否保持。固定换镜频率和特效数量都不能替代这项判断。

## 用户拒绝就是当前版本的审阅结果

保留绑定本版文件哈希的反馈、问题区间和原审阅证据；将对应audio／visual等维度记为failed，不继续称“参考风格已完成”。工程通过独立保留。下一版要用对应位置的实际声音和画面证明问题得到处理；改技能、写计划、机器零警告均不能改写成片验收结果。

作者要求实施前确认时，方案同时写清保留的原版元素、本次借鉴的变化、拟沉淀到 AGENTS.md 的条目和需要定稿的固定台词。试剪长度与是否扩展到整片按本期约定执行。
