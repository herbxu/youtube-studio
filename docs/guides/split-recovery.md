# 历史三仓切换与回退

此文记录旧版恢复方式。现行工作流见[两仓目录契约](repository-structure.md)。

拆分前 youtube 的 HEAD 为 d3bf0d5，保留在原仓库。切换没有创建提交、变更远端、恢复用户已删除的 ZIP 或修改暂存区。代码库与工作台当前内容需单独版本化；提交媒体前先配置 Git LFS。

- [迁移路径清单及原片 SHA-256](../decisions/three-repositories-2026-11-10.json)。路径相对原作品库；历史审批记录与 QA 不重新签署。
- 原本的内容保存在工作台本地 runtime/pre-split-d3bf0d5/original（切换前快照，含隐藏数据及凭证）。removed-at-cutover 保存实际移出的副本。该目录已忽略且受本地权限保护，不打包，不上传。
- 需要回退时，先停止制作，独立备份三个仓库切换后的修改及当前 Git 索引；将 original 复制到新的私有空目录作完整恢复验证，而不要直接覆盖现有 .git。需要局部还原时按路径清单从 removed-at-cutover 取回相应文件，遇到同名更新先比对，再合并。
- 已生成的 HTML、字幕和正式 MP4 均非迁移验收的替代品。发布仍使用各集 deliverables；旧绝对路径按清单解析。未做新一轮整片听审或整片渲染。
