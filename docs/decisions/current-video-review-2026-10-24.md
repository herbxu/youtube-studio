# 当前样片复盘与素材工作流

> 目录迁移补注：本文记录当时的实现与验收。表达样片、杂志拼贴样片两套旧工程已删除；连续场景样片现位于 `examples/competition-continuity/`。历史路径由[迁移清单](layout-migration-2026-10-24.json)映射，未重新渲染或增加听审结论。对照证据在本目录 `evidence/`。

对象：35.76 秒《竞争优势》杂志拼贴样片文字动画版，SHA-256 为 584948fc33d292859972617301b4760a21ffd0343a497b9f004bdf952c9df49d。依据是实际导出抽帧、分镜与动画时间线；没有进行全程连续播放和主观听审，以下不对声音自然程度打分，也不将选段边界问题推断为完整脚本的问题。

## 主要问题

1. **画面仍以页面为单位。** 固定页眉、页码、标题、正文区、脚注及换页叠化，让人持续感受到展示页面。前两轮主要改了媒体类型和文字入场，没有充分改变以对象动作推进叙事的方式。
2. **前 16.75 秒素材变化有限。** 第一张咖啡店照片出现在三个镜头中，第二张只作并置；没有顾客进出、开店、分流等实际动作。复用本身可以有效，但这里没有通过复用揭示新的关系。
3. **16.75–23.68 秒跳过了中间机制。** 店铺增加后，利润色块直接收缩。观众能看到结论，却看不到顾客被分流、竞争者降价或成本变化的具体路径。下一版应选择一种明确的假设路径，不把这些可能路径全都塞在一起或当作普遍事实。
4. **28.10–35.76 秒的条形图含义不够清楚。** 长度并不对应已定义的指标，“制度 / 人才 / 管理”同时出现在两条下方，主要是在表达抽象的追赶。更适合展示某项具体优势如何被模仿，并同时保留难以复制的条件。
5. **文字层级仍偏多，动画模式也趋同。** 标题、说明、图解标签、署名、边界说明和字幕在竞争注意力；每个镜头都使用相似的上滑和红色划线，会形成新的模板感。应让关键判断有强调，普通叙述更多交给媒体。
6. **存在语义与动作时序不够贴切的细节。** 30.44–32.10 秒口播说“制度人才管理”，对应图中文字到 32.72 秒才跟随“对手挖一挖”出现。程序有时间锚点，不等于锚点选得合理。末尾口播“迟早也追上来”和标题“可能被追上”的判断强度也不同，应在内容审读时统一；不能只改字幕。

“测试通过”确认了时间、布局和输出的工程正确性，没有证明观看体验已经成熟。现阶段更值得改进的是视觉叙事与素材选择；给所有字继续加特效，收益有限。

## 借鉴小A的方式

依据此前本地样本调研，小A的可迁移特点是实拍承接、实物拼贴、简单关系变化与重点文字交替。没有充分听审证据支持断言其固定 BGM 类型、BPM 或音效公式，因此音乐与音效策略需要本项目试用后再判断。

针对本段，可以准备：店铺营业短视频；门口/顾客等可操作对象；用于解释顾客分流的清楚示意；产品或服务被模仿的具体对象；必要动作上的轻音效；可选、稀疏且不压人声的背景音乐。来源页与下载素材都不能自动作为真实经营证据。

## 新建的素材 skill

[youtube-media](../../skills/youtube-media/SKILL.md) 负责由 agent 按脚本形成需求、检索候选、检查来源与素材、保存本地文件和使用计划。它与 youtube-visuals 分工：前者选择解释所需的素材，后者编排关系、版式和动作。

现有 media-use 是可调用的底层能力。2026-10-24 的本机 doctor 结果：19 个内置音效可用，FFmpeg/ffprobe 与 Node 可用；HeyGen CLI 未安装，版本和认证状态不可用。因此在线目录检索尚未实机跑通；可使用可访问的素材站或用户已有素材继续准备。

当前 Python 程序支持图片编排，尚未实现实拍视频片段、BGM/SFX 轨道与 ducking 混音。新 skill 输出的素材计划会明确标记这些接入缺口。BGM 是背景音乐，BPM 是节拍速度，后者可作为选曲或节拍分析字段；不能混为一类素材。
