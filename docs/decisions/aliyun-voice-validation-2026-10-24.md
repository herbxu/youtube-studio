2026-10-24，用户授权使用自有录音和阿里云服务。密钥仅从本机配置读取；实现与用法见 [配置指南](../guides/aliyun-voice.md)。

## 已验证

- 用户提供的北京 qianwenaiapi 接入地址能够完成音色列表查询、创建、状态查询及语音合成。
- 已接入原生 aliyun provider，复用生产流程的内容缓存；支持 CosyVoice 和 Qwen-Audio 的同一套 HTTP 协议。此次实际调用 cosyvoice-v3.5-plus 和 qwen-audio-3.0-tts-plus。
- 本轮共54项测试通过；新增检查覆盖环境变量读取、地址限制、请求失败不自动重试、模型与音色绑定、下载恢复不再提交POST。
- 本机密钥文件及生成音频均受 Git 忽略。未发布视频或提交 Git。

## 样音与用户反馈

第一版使用原音频5.4–21.25秒，服务默认最多使用10秒参考，并附加平静自然的风格指令。生成20.56秒中文样音后，用户评价“声音不像”“有点太假了”。此版本已拒绝，不用于后续制作；当时 voice_verified 保持 false。

第二轮改用原音频111.05–139.10秒的完整解释句群，显式使用28秒参考，去掉风格指令，并以同一段文字比较两个模型：

| 候选 | 模型 | 实际时长 |
|---|---|---|
| cosy-natural-v2 | cosyvoice-v3.5-plus | 17.52秒 |
| qwen-natural-v1 | qwen-audio-3.0-tts-plus | 18.16秒 |

文件位于本期 media/voice-samples；创建ID、参数、正文、音频哈希及自动转写记录位于 source/voice-candidates。用户随后明确反馈“B 更合适，可以继续”，因此已选定 qwen-natural-v1，配置中的 voice_verified 为 true。此批准对应样音，不代表整片听审已经通过。

## 已修复的接入问题

首次较长样音请求返回后，下载器拒绝了非HTTPS地址且未提前保存响应，因此没有取得该音频。该请求的费用及服务端结果未核实，原缓存保持 uncertain，未自动重复原请求。

之后修复为先落盘响应、再解析下载；新诊断请求实际证实阿里 OSS 媒体地址可为 HTTP，现在对同一 OSS 地址使用 HTTPS 下载。响应中临时签名链接只保存在本机缓存，下载不携带 API Key。回归测试验证下载失败后可复用同一响应，避免再次合成。

## 选定 B 后的生产验证

使用 qwen-audio-3.0-tts-plus 为《企业再融资》的五段完整论证选段生成旁白，总长83.12秒。第一段复用用户批准的原始 B 样音，其余四段按相同模型和音色合成。没有把这段验证片称为历史长稿的完整整期。

独立 Whisper small 识别保留了“增发/蒸发、摊薄/贪薄、融资/笼子、认购/论购”等差异，数字也有中文与阿拉伯数字格式差异。为取得可靠动画锚点，新增本机 `whisper-forced`：独立识别留档后，以原稿为参考做声学注意力与 DTW 对齐；不按字数均分，不降低94%的覆盖门槛。参考约束覆盖率100%只说明映射完整，不能据此认定所有读音正确。整片读音与自然度仍待审听。

生产链已实际执行脚本 → 配音 → 对齐 → 素材 → 编排 → 渲染 → 导出检查。视频使用1920×1080、30fps，47条同步字幕，无额外背景音乐。画面包含公司融资前后、100→125份股份与10%→8%、普通债的偿付关系、真实公告用途高亮和三个判断要点的逐步出现。

实际MP4抽帧发现结尾第一个关键词等待约4秒，已修改脚本让“代价”随场景入场，后两项继续跟随口播，复用全部配音重新导出。机器检查和抽帧不能替代整片听审与连续观看；最终指标、文件哈希以本期 `deliverables/qa.json` 为准，审阅范围记录在 `review.json`。

新增强制对齐测试覆盖独立识别差异保留、零时长词合并、超长片段拒绝和无声学结果时拒绝编造。54项测试全部通过。渲染继续使用锁定的 HyperFrames 0.8.171，未中途升级、提交 Git 或上传发布。

最终输出：`episodes/20260913-企业再融资-增发和发债/deliverables/output.mp4`。机器测得时长偏差0.013333秒、综合响度-18.0 LUFS、真峰值-1.51 dBTP；无持续黑场，五处底边检查通过。最终11张关键抽帧已查看，记录绑定MP4哈希 `1cf9087ce280c065fbe09fcc32947e28cdb7ed0fe6c83bb91b41c455bdaca53e`。质量状态保持 needs_review，原因是整段主观听审与连续观看尚未完成。
