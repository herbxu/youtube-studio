## 内容与视觉

入口是 [本期 script.json](../../episodes/20260913-企业再融资-增发和发债/script.json)。论证顺序为：融资后的钱和代价 → 增发的持股比例 → 普通债务的偿付义务 → 公告用途计划 → 具体判断问题。借鉴小A用对象与关系解释问题，结合思维咖啡的认知递进和结论边界。

原文证据使用 [小米集团2025年3月25日公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2025/0325/2025032500008_c.pdf) 第3页用途段落。原 PDF、截图坐标和哈希记录在本期 source/evidence；画面说明用途计划不等于实际回报。没有把早期稿件的未核实说法带入新稿。

`evidence` 用实际截图及归一化高亮区域；`object_scene` 保留对象身份，通过 reveal、move、context、connect、emphasize 逐步解释。同场景跨口播单元只创建一组对象；已连接对象暂不支持继续移动。公司、现金、人物、文书是代码图形，也可使用有来源的本地图片。不是任意图表引擎。

布局原型在根目录 build/explain-contract，采用85秒合成测试时序，明确标注“布局验证 · 合成时序 · 无旁白”。它不代表实际口播时长、ASR 对齐或已完成的视频。

## 验证结果

- 44 项单元/集成测试通过，包括声音缓存复用、素材变更、音轨时长、对象状态及质量证据绑定。
- 浏览器检查通过4组正反向定位、9个几何采样。
- HyperFrames 0.8.171 检查：零错误；运行、布局、38项对比度检查通过。保留5条嵌套结构建议，当前未改为子合成。该检查未启用其 motion 检测，不能据此宣称完整运动验收。
- 人工查看实际抽帧后放大公告原文，替换抽象对象并加入现金移动；抽帧检查不代替最终连续观看。
- 素材库检查及五个 skills 的格式验证结果见 [验证记录](skills-improvement-validation-2026-10-24.json)。

## 首轮配音阻塞与接续（已由后续接入解除）

用户提供的音色参考约525.22秒，原文件已保留，副本位于本期 media/voice-reference。测得输入综合响度 -23.06 LUFS、真峰值 -3.63 dBTP、响度范围5.30 LU；这些是输入测量，未完成主观听审或声音克隆。

当前会话没有可直接调用的内置音色克隆服务。项目采用可配置 provider，但没有可执行的云端适配命令、服务名或 voice_id。本期 doctor 明确阻止回退默认音色；没有上传参考音频或发出付费生成请求。

接续顺序：确定服务及本机凭证 → 接入适配器和音色 ID → 生成包含提问、数字和转折的短样本并听审 → 设置已验证音色 → 生成完整旁白 → 实测对齐 → 编排渲染 → 听审与连续观看。`quality` 的 reviewed 状态需要绑定本版 MP4 哈希和输入指纹的实际审阅证据。
