# 视觉方向改版：摄影拼贴与动态图解

> 目录迁移补注：本文记录当时的实现与验收。表达样片、杂志拼贴样片两套旧工程已删除；连续场景样片现位于 `examples/competition-continuity/`。历史路径由[迁移清单](layout-migration-2026-10-24.json)映射，未重新渲染或增加听审结论。对照证据在本目录 `evidence/`。

默认风格已从整片叙事插画改为 `editorial-magazine/v1`：照片建立生活场景，动态图解解释竞争关系，短句承载作者判断。插画保留给确有必要的比喻。历史剧集及原插画样片没有覆盖。

## 当前实现

- 新建剧集使用深墨、砖红与浅纸色，统一字体、字幕、注释和页眉。
- 新增 collage：hero 摄影版式、duo 两图并置，第二张照片按词时间戳出现；支持独立来源、署名、假设场景说明。
- 新增 mechanism：竞争进入 / 扩产 / 利润空间收缩，以及竞争对手追近领先者。图形仅为定性示意，不承担实际数据含义。
- 保留观点短句、概念对比、三步关系、持股比例变化和局部插画模板。选择依据是解释任务，不设媒体配额。
- 写作、视觉和制作 skills、默认配置、README 与 AGENTS 已同步。配音继续优先采用作者提供的真实录音。
- 第二张图片纳入文件哈希、素材校验和编排包；替换素材会使旧结果失效，配音缓存仍可复用。

机器检查保存在样片 `build/qa.json`、`build/motion-regression.json`，人工检查范围单独保存在 `production/review.json`，不会被流水线重跑覆盖。

## 第二轮：文字动画

针对整块文字同时出现的问题，6 个镜头的标题改为 12 个语义组，按真实口播锚点出现。组内使用短促的逐字上滑，重点词随后画线；引导语延后进入，追赶图解的双方名称与说明分层进入。字幕、来源和必要条件仍保持稳定，原录音未修改。

修改前成片保留在 `production/build/output-before-text-motion.mp4`，当前 `output.mp4` 为文字动画版。新增 headline_parts 的完整性、时间范围及倒序 seek 检查；本轮 28 项 Python 测试、19 项浏览器运动检查和 20 条字幕安全区检查通过。最新实际导出及人工抽帧范围以 `production/review.json` 为准。
