## 实际变化

- 0–6.62 秒：咖啡服务实拍，保留一个问题“别人能复制吗？”。视频全画幅，去除源音轨；摄影建立情境，不承担后续竞争事实。
- 6.62–11.13 秒：转入明确标注的假设街区，原店留下，隔壁出现新店。
- 11.13–23.68 秒：同一批顾客先集中在原店，再流向新进入者及扩产的对手。原店接到的订单减少，随后显示利润承压。条件明确为总需求、单价和成本条件不变；顾客图符数量是解释道具，不能当实际数据。
- 23.68–28.10 秒：保留原店与隔壁店，镜头靠近它们，收住“做得好，还要守得住”。
- 28.10–35.76 秒：原店的特色服务被对手复制；制度、人才、管理依照各自口播时间出场，再从原店移动到对手，最终提出“什么难以复制？”。不再使用含义不明确的追赶条形图。

去掉了页码、反复出现的杂志刊头和各段重新铺满的大标题。场景只创建一次，跨三个口播单元复用对象。动画的主要职责是演示进入、分流、复制，不再只让文字上浮。

作者第三段录音实际剪掉“迟早也追上来”，保留到该句之前的自然间隔并淡出，末尾留短暂停顿给问题。字幕和 words 同时删掉这一句，前面的时间戳保留。详见 `media/recordings/edit-decision.json`；原始 `u-copy.wav` 仍在，不是只改字幕。

声音增加两处低增益轻 click，绑定“开一家”和“对手挖一挖”。没有选用 BGM，没有估算 BPM；先验证解释效果与口播空间。

## 已接入生产程序

| 能力 | 实现与边界 |
|---|---|
| 本地实拍 | `footage`：来源、source_in、focus、实测镜头时长、裁切到 1920×1080、30fps、剥离源音轨；不足时长直接失败 |
| 连续对象 | `continuity` / `shop-competition/v1`：16 个按口播锚定的动作，跨单元保持 DOM；只支持这一完整机制，不是通用动画编辑器 |
| 音轨 | 单元 `audio_tracks`：本地 SFX/BGM、真实 cue、裁切、增益、淡入淡出、人声侧链压低；保留 voice.master.wav，另生成 audio.mixed.wav |
| 素材记录 | 本次实际输出 media-plan.json、media/manifest.json、media-review.md；图片/视频资产冻结仍由 assets 阶段负责 |
| 验收 | 增加越界视频拒绝、动作时间约束、对象持续性、逆向 seek、声音侧链压低、精确时长和源文件不改写测试 |

素材搜索仍由 agent 按 `youtube-media` 执行，不是 `youtube-studio run` 里的无人值守搜索阶段。HeyGen CLI/登录尚不可用；本轮实拍来自公开 Pexels 下载入口，SFX 来自 media-use 已安装的内置库。BGM 的混音能力经过合成信号测试，没有实际音乐选择和听审。

实现入口：`src/youtube_studio/continuity.py`、`audio_mix.py`、`composition.py`、`pipeline.py`；脚本契约及技能说明已同步。旧模板和原剧集没有批量重写，新项目默认配置仍保留摄影拼贴方向，连续场景在本独立样片中验证。
