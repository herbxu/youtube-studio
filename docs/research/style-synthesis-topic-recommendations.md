# 博主风格综合分析与六个主题的修改建议

日期：2026-10-25。依据已有小A系列、思维咖啡及一口新饭研究报告，六期历史原稿、两期当前 script.json、视觉契约及生产程序。只提出内容与制作建议，不修改作者原稿、配音或生产代码；不新增对市场数据的核验结论。

> 后续状态更新（2026-10-25）：本文以下记录的是较早时点。《企业再融资》随后已扩展为 37 段完整输入，本文关于五段验证片的描述不再代表最新脚本。最新职责分工、流程审查和实施顺序见 [trade → youtube 自动制作流程审查与改进计划](trade-youtube-automation-review-plan.md)；成片完成情况以匹配当前输入的交付和审阅记录为准。

## 方向判断

采用“个人判断驱动、原始材料支持、连续对象解释”的频道表达。小A提供短篇机制解释与模块组织参考；思维咖啡提供生活化问题、代入与边界；一口新饭提供观点冲突、个人困惑与核心模型反复演进的参考。

不建议将三人的外观混成一套，也不要求真人出镜或固定画面配额。保留摄影拼贴、证据与动态图解的方向，让素材服从本期需要解决的问题。没有足够来源的案例，不因画面好看而加入。

## 三组样本的可迁移差异

| 维度 | 小A | 思维咖啡 | 一口新饭 | 本项目选择 |
|---|---|---|---|---|
| 选题入口 | 具体矛盾与反直觉 | 生活处境与自问 | 作者困惑与观点冲突 | 每期只确定一个主问题 |
| 推进 | 解释机制、形成检查问题 | 举例、换角度、补充边界 | 提问、反驳、修正、回收 | 按主题选，不套统一公式 |
| 画面 | 真人、实拍、实物拼贴与小动画 | 情境插画与短概念文字 | 真人与持续演进的模型 | 真实资料建立依据，对象变化解释关系 |
| 作者感 | 稳定讲述者 | 生活共鸣与个人感想 | 经历、选择与承认误解 | 使用已有真实复盘，不虚构第一人称 |
| 最值得复用 | 独立论证模块 | 同一情境承接几句话 | 同一模型承载新层次 | 每章围绕一个持续可识别的对象 |
| 不直接照搬 | 换景密度、泛财经素材 | 全片水彩与重复生活例子 | 长时间悬念、金融模型泛化 | 保留短而清楚的主线与条件 |

样本长度和数量不同，不能据此排名频道整体质量。响度与语速数据也不应直接复制为制作标准。

## 当前差距：规范已有，落到单期仍不一致

写作技能已经要求主问题、判断、依据和边界；视觉技能已经要求对象连续、证据截图与口播锚点，因此无需再把这些列成“新增全部能力”。

实际输入上，《竞争优势》的当前脚本仍有 21 个单元，画面类别只有 illustration/comparison/flow，且未填写 narrative；《企业再融资》的当前输入有 5 个单元，已经使用 narrative、evidence、object_scene、quantity 和 cover。这说明首先要把现有能力应用到真实剧集，而不是继续增加通用模板。

《企业再融资》review.json 明确标为“五段完整论证验证片，不是历史长稿的完整整期”；工程检查通过，内容、主观听审与连续视觉审阅仍待完成。不能将这个验证片说成历史整期已经完成。《竞争优势》原剧集与 examples 的连续街区样片也应分别表述。

## 六个主题的具体修改

### 1. 竞争优势：从概念清单变成一次竞争测试

主问题：产品做得好，为什么利润仍可能留不住？

建议顺序：一家店生意不错 → 对手能否进入 → 同一批顾客如何被分流 → 哪些优势可复制 → 什么条件才能阻止复制 → 回到真实公司的局部业务验证。书籍和分类放在观众需要解释的时候引入。

贯穿对象：原店、对手和顾客。先利用已经存在的街区机制验证方式，再转真实企业证据；不让每家公司都重新引出一套概念。主案例保留一到两个，其他公司只承担不同的反例任务。

原稿“差异化护不住任何东西”“迟早追上来”等表达应逐句审读，说明差异化是否难以复制、竞争进入是否受限。已有录音改判断必须实际剪辑或重录，不能只改画面。

可行性：高。街区模板已有专项实现；原剧集迁移仍需改分镜、对齐真实录音并重新验收。它只解释特定假设，不是所有行业的竞争仿真。

### 2. 企业再融资：按股东的问题组织，而不是工具目录

主问题：公司拿到钱以后，老股东到底付出了什么，又可能得到什么？

建议顺序：股东持有比例变化 → 公司新增资金 → 公告承诺的用途 → 后续执行与回报尚待验证 → 普通债、可转债等工具改变了哪一种代价。保留当前五单元验证片的清楚主线，再决定历史长稿哪些案例值得并入。

贯穿对象：同一公司、原股东、股份总量、进入公司的现金。quantity 只解释“持有数量不变、总量变化”；现金进入和资金用途用 object_scene 与 evidence 接续。不要把比例下降直接等同于财富按相同比例损失。

历史稿“一年内增发不再主动买入”如保留，应标明是作者筛选偏好，并与普遍的融资判断分开。当前已改写的部分不重复重做。

可行性：最高。当前脚本已经使用相关能力。下一步先完成来源核对、整段播放和听审；不必先开发复杂蛋糕动画、债券定价或多路径现金仿真。

### 3. 长期持有：用买入理由的变化推动故事

主问题：我现在是在坚持一个仍成立的判断，还是在为过去的决定找理由？

建议顺序：明确“为什么买” → 当时可观察的理由 → 出现了什么新事实 → 判断被强化还是被推翻 → 重新比较持有的理由与约束。个人经历只使用 trade 真实记录，模拟情境明确标注。

贯穿对象：一张买入理由卡，原来的判断留在画面中，逐条加入支持与反对的证据。结尾给出复查问题，而非把技术指标、指数选择和卖出方法同时讲成三个新主题。

历史稿将均线跌破说成基本面恶化的明确信号，需要独立论证；风格修改不能解决证据不足。可将它改为引出“价格提醒与经营事实有何区别”的审读问题，具体结论待来源核实。

可行性：中高。证据与对象关系已有入口，但动态清单的删除线、状态切换没有通用动作；第一版用短标签、强调和证据并置即可。无需先开发完整投资复盘软件。

### 4. 梯子：让观众看见被筛掉的样本

主问题：眼前这些成功案例，足以说明一个方法可靠吗？

建议顺序：先展示若干被推荐的对象 → 所有对象仍留在场上 → 只高亮后来被展示的赢家 → 问未展示的结果在哪里 → 讨论完整记录、成本、行情条件和失效边界。避免让后半段反复停留在泛泛的独立思考劝告。

贯穿对象：同一批样本。没有完整真实记录时，用少量明确标记的假设卡片解释筛选，不能伪装成实测回测。原稿声称做过测试，应先找到记录与方法。

可行性：中。当前 object_scene 最多六个对象，也没有通用隐藏、筛选和任意折线动作；先用四至六张卡片与强调即可说明问题。真实收益曲线、交易成本回测与大样本筛选需另做数据与程序，不建议为本期先建设完整回测平台。

### 5. 投资中最简单的事：从读书介绍改成决策顺序

主问题：好公司、便宜和好时机发生冲突时，我先判断什么？

建议顺序：先抛出一个选择困境 → 检查企业质量 → 检查价格对应的假设 → 最后处理入场与约束 → 回到开头选择。作者和书名简短介绍；删去不改变判断的重复赞誉。

贯穿对象：同一家公司，在不同价格与判断条件下保持身份；不把“质量、估值、时机”只做成三个轮流出现的大标题。

“便宜的坏公司优先于贵的好公司”应区分原书观点、适用条件与作者立场，也要与《竞争优势》关于价值陷阱的论述一致。不要靠金句强度掩盖概念冲突。

可行性：高。context、comparison、flow 与证据图可以完成首版。若原稿压缩后仍包含两条独立论证，再考虑拆集；不因小A有系列就机械拆成同样时长。

### 6. 腾讯财报：围绕一个经营疑问组织证据

主问题：现金流变化说明了经营恶化，还是资金投入与回报时间发生变化？

建议顺序：一项反常数据 → 对应原表及口径 → 拆开已发生的资金支出、管理层解释与未来回报假设 → 观察哪些后续指标能支持或推翻解释。其余业务成绩只保留与这个判断有关的部分。

贯穿对象：同一张财报局部和资金去向关系。原始值与调整值并列，调整项有来源；无法核对的值不画成确定的桥接图。历史稿的具体数值，本次不视为已核验。

“会计游戏”等措辞可能比证据更确定，应在审稿时区分真实现金支出与解释性调整；不把管理层说明等同于回报必然兑现。

可行性：中。资料高亮与静态原图可直接用；真实财务桥接图、任意时间序列图和同比联动仍需数据准备及额外实现。优先做局部原文和两三个清楚的值，不先建通用图表系统。

## 能力与实施成本

以下“已有”来自代码与契约检查，不等于本次重新渲染通过：

| 建议 | 当前边界 | 投入与执行建议 |
|---|---|---|
| 主问题、章节递进、作者立场 | narrative 与 argument 已有 | 低；先审稿，避免额外并行正文 |
| 原文截图局部高亮 | evidence 已接入 | 中；主要投入是找原始来源、选区域、核口径 |
| 同一对象跨单元保留 | object_scene 已有 | 中；1–6 对象，出现、移动、强调、情境与连接；已连接对象不能继续移动 |
| 店铺竞争、顾客分流与复制 | shop-competition/v1 已有 | 中；仅复用适用的假设机制，不推广成通用动画 |
| 持股比例改变 | quantity 已有 | 低；仅限固定持有量、变化总量 |
| 实拍、BGM/SFX 与人声压低 | 代码已有接入，素材仍由 agent 准备 | 中；先选必要素材、检查来源；音乐选择和听感需播放判断 |
| 大量样本筛选、任意曲线、财务桥接图 | 尚无通用模板 | 高；本轮采用简化图解或已核对静态图 |
| 名人口型、复杂角色、三维场景 | 当前建议不需要 | 不优先；无法解决稿件论证和来源问题 |

不提供伪精确制作工时：实际成本取决于正式录音可否复用、证据是否齐全，以及是否产生新素材费用。口播改动比单纯画面改动更可能带来配音和重新对齐成本。

## 建议执行顺序与验收

1. 先完成《企业再融资》当前验证片的内容、连续视觉与听审。若有效，沿用现有对象体系完善历史整期，不推翻已经清楚的部分。
2. 用《竞争优势》已有正式录音挑一段完整机制，验证持续对象确实比原有逐段插画更清楚。保留作者声音，必要改句另行实际处理。
3. 将《长期持有》作为真实复盘表达的下一期：先补事实与理由卡，再制作。
4. 梯子、读书与财报分别按筛选机制、决策顺序、证据解释重组；财报以资料核验为前置，不因时效性急于渲染。

每个试段只考察一个明确问题：观众是否看到了机制，而不仅看到了结论？静音时能辨认对象关系，纯听时能理解论证，声画合看没有互相矛盾；证据、假设和个人判断能区分。通过结构与布局检查后仍需实际连续播放，改判断必须同步口播、字幕与画面。

本次仅形成建议并检查文档链接；没有改动生产程序、正式脚本、声音或视频，也没有新增事实核验及成片验收结论。
